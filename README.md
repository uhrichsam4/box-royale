# Box Royale

A browser build-and-shoot battle royale: 16 fighters, bots fill the empty slots, a storm circle shrinks, last one standing wins.

**Play:** https://uhrichsam4.github.io/box-royale/

- **Solo:** fight 15 bots.
- **Online:** one person clicks *Host online match* and shares the 5-letter code or link; friends join, then the host presses **Enter** to start. Connections are peer-to-peer (WebRTC via PeerJS), so no server is needed.

Controls: WASD move · Space jump · Left click shoot · Q wall · E ramp · F floor
